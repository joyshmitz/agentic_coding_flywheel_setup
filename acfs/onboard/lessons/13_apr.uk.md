# Що таке APR?

Складні специфікації потребують декількох циклів перегляду для виявлення архітектурних проблем, крайніх випадків та недоліків безпеки. Замість ручного проведення 15-20 раундів перевірки AI, APR автоматизує цей процес.

**APR (Automated Plan Reviser Pro)** організовує ітеративне удосконалення специфікацій за допомогою розширених міркувань AI. Ранні раунди виправляють основні проблеми, середні раунди удосконалюють структуру, пізні раунди полірують абстракції.

---

# Перевірка встановлення

Перевірте, що APR встановлено:

```bash
apr --version
```

І перегляньте доступні опції:

```bash
apr --help
```

---

# Базовий робочий процес

APR працює з файлами планів Markdown. Типовий процес виглядає так:

1. Згенеруйте початковий план (з Claude Code або напишіть самостійно)
2. Запустіть `apr refine`, щоб покращити його
3. Перегляньте удосконалений план
4. Передайте його назад до Claude Code для реалізації

---

# Удосконалення плану

Припустимо, у вас є файл плану з назвою `plan.md`. Удосконаліть його:

```bash
apr refine plan.md
```

APR аналізує план і виводить покращену версію з:
- Більш чіткою структурою
- Виявленими залежностями
- Потенційними крайніми випадками
- Більш дієвими кроками

---

# Збереження у конкретний файл

За замовчуванням APR виводить до stdout. Збережіть у конкретний файл:

```bash
apr refine plan.md -o refined-plan.md
```

Тепер у вас є обидві версії для порівняння.

---

# Ітеративне удосконалення

APR підтримує декілька проходів. Якщо перше удосконалення недостатньо ретельне:

```bash
apr refine refined-plan.md -o final-plan.md
```

Кожен прохід додає більше деталей та структури.

---

# Практичний приклад

Ось справжній робочий процес:

```bash
# 1. Claude Code генерує початковий план
# (створює plan.md)

# 2. Удосконалюйте за допомогою APR
apr refine plan.md -o refined-plan.md

# 3. Перегляньте результат
cat refined-plan.md

# 4. Передайте Claude Code для реалізації
# "Будь ласка, реалізуйте відповідно до refined-plan.md"
```

---

# Підсумок

Ви дізналися:
1. **APR** перетворює чернеткові плани на відполіровані дорожні карти
2. **apr refine <file>** обробляє файл плану
3. **-o** зберігає вивід у конкретний файл
4. Використовуйте APR ітеративно для складних планів

APR особливо корисний, коли ви хочете, щоб Claude Code слідував добре структурованому плану реалізації.
