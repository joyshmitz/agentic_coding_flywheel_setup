# Що таке XF?

**XF** надає блискавично швидкий повнотекстовий пошук по вашому особистому архіву X/Twitter: твіти, лайки, DM та розмови з Grok. Все індексування та запити відбуваються 100% локально.

Побудований з Tantivy та SQLite, він поєднує BM25 пошук за ключовими словами з семантичною схожістю для гібридного пошуку. Індексування ~10,000 документів/секунда, запити за суб-мілісекунди.

---

# Хто потребує цього?

XF корисний, якщо ви:
- Хочете знайти старі розмови чи посилання
- Будуєте набори даних з вашої історії твітів
- Потрібно швидко шукати по вашій присутності в соціальних мережах

Це опціональна утиліта, не обов'язкова для agentic coding workflow.

---

# Базове використання

Спочатку індексуйте ваш архів (одноразове налаштування):

```bash
xf index ~/Downloads/twitter-archive
```

Потім шукайте:

```bash
xf search "machine learning"
```

---

# Фільтрація за датою

Пошук у конкретному часовому періоді:

```bash
xf search "rust" --from 2024-01-01 --to 2024-06-30
```

---

# Експорт результатів

Вивід у JSON для подальшої обробки:

```bash
xf search "AI" --format json > results.json
```

---

# Підсумок

XF є швидким інструментом пошуку архівів:
1. **xf index** — Індексуйте ваш архів (одноразово)
2. **xf search** — Запитуйте ваші твіти
3. **--from/--to** — Фільтруйте за датою
4. **--format json** — Експортуйте результати

Використовуйте його, коли потрібно швидко шукати по вашій історії Twitter.
