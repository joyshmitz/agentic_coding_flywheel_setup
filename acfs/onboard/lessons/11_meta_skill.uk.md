# Що таке Skills?

AI-агенти як Claude Code потужні, але вони не знають ваших специфічних проектних конвенцій або унікальних робочих процесів з коробки.

**Skills** це шаблони промптів для повторного використання, які надають агентам нові можливості. Вони як "плагіни" для вашого AI.

Ми використовуємо **meta_skill (ms)** для керування цими skills локально. Це інструмент управління знаннями, що працює локально, з гібридним семантичним пошуком (BM25 + hash embeddings) та аудиторськими слідами на основі Git. Ваші skills живуть у вашому проектному репозиторії, а не в хмарі.

# Перевірка встановлення

Спочатку переконаємось, що `ms` встановлено і працює правильно.

Запустіть перевірку версії:

```bash
ms --version
```

Потім запустіть перевірку doctor, щоб переконатись, що все правильно налаштовано:

```bash
ms doctor
```

---

# Ініціалізація проєкту

Щоб використовувати skills у проєкті, ви ініціалізуєте `ms`. Це створює директорію `.ms/`, де житимуть ваші проєкт-специфічні skills.

Спробуйте ініціалізувати у вашій поточній директорії:

```bash
ms init
```

Ви повинні побачити повідомлення, що підтверджує створення `.ms/config.toml`.

---

# Відкриття та пропозиції

`ms` використовує розумний алгоритм пошуку (Thompson sampling) для пропозиції найефективніших skills для заданого завдання.

Уявіть, що ви хочете написати тест. Попросіть `ms` дати пропозиції:

```bash
ms suggest "написати unit test"
```

Якби у вас були встановлені skills, він би показав найкращі відповідні.

Ви також можете перелічити всі доступні skills:

```bash
ms list
```

# Створення Skill

Давайте створимо простий skill. Skills це просто Markdown файли з деякими YAML метаданими.

Створіть новий skill під назвою "hello":

```bash
ms create "hello"
```

Це відкриє ваш редактор. Ви можете визначити, що робить skill (наприклад, "Привітайтесь з користувачем піратським голосом").

# З'єднання з MCP

Магія відбувається, коли ви з'єднуєте `ms` з Claude Code через **Model Context Protocol (MCP)**.

ACFS налаштовує це автоматично! Коли ви запускаєте Claude Code (через `cc`), він може "бачити" ваші `ms` skills як нативні інструменти.

Якщо вам колись знадобиться запустити MCP сервер вручну (рідко), ви можете виконати:

```bash
ms mcp serve
```

(Натисніть Ctrl+C, щоб зупинити його, якщо ви його запустили)

# Підсумок

Ви дізналися:
1. **ms** керує AI skills локально у вашому проєкті.
2. **ms init** налаштовує проєкт.
3. **ms suggest** знаходить правильний skill для роботи.
4. **MCP** з'єднує ці skills з Claude Code автоматично.

Далі ми подивимось, як знайти *віддалені* skills від спільноти, використовуючи `jfp`.
