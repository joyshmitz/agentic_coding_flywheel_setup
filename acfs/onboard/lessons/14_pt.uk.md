# Що таке PT?

Чи траплялося у вас 23 застрягнених процеси `bun test`, що перевантажували вашу машину? PT був створений саме для цієї проблеми.

**PT (Process Triage)** ідентифікує та знищує покинуті або зомбі-процеси, використовуючи алгоритм оцінки, натхненний Байєсівським підходом. Він оцінює тип процесу, вік, статус сироти та використання ресурсів, щоб ранжувати кандидатів за імовірністю покинутості.

---

# Перевірка встановлення

Перевірте, що PT встановлено:

```bash
pt --help
```

---

# Швидкий огляд

Отримайте знімок того, що працює:

```bash
pt
```

Це показує резюме активних процесів, організованих за використанням ресурсів.

---

# Пошук споживачів ресурсів

Що споживає найбільше CPU та пам'яті?

```bash
pt --top
```

Це ранжирує процеси за споживанням ресурсів, полегшуючи виявлення проблем.

---

# Пошук процесів

Шукаєте щось конкретне? Шукайте за назвою:

```bash
pt search node
```

Це знаходить усі процеси, що відповідають "node" та показує їх використання ресурсів.

---

# Пошук користувачів порту

Потрібно знати, що використовує порт 3000?

```bash
pt --port 3000
```

Це безцінно при налагодженні помилок "port already in use".

---

# Чому PT важливий для агентів

Коли AI агенти запускають збірки, тести або компіляції, вони можуть породжувати багато процесів. PT допомагає діагностувати:

- Чому збірка повільна
- Що споживає пам'ять
- Які процеси застрягли
- Конфлікти портів

---

# Типові сценарії

```bash
# Збірка працює повільно? Перевірте, що конкурує за CPU
pt --top

# Не можете запустити dev сервер? Знайдіть, що використовує порт
pt --port 3000

# Проблеми з пам'яттю? Знайдіть винуватців
pt search --sort-by memory
```

---

# Підсумок

Ви дізналися:
1. **pt** — Швидкий огляд процесів
2. **pt --top** — Знаходження споживачів ресурсів
3. **pt search** — Пошук конкретних процесів
4. **pt --port** — Ідентифікація користувачів порту

PT є діагностичним інструментом, що допомагає зрозуміти, що відбувається у вашій системі.
