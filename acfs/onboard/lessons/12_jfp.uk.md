# Що таке JFP?

В Уроці 11 ви дізналися, як `ms` керує skills локально. Але звідки беруться хороші skills?

**JFP (JeffreysPrompts.com CLI)** надає доступ до курованої бібліотеки випробуваних промптів для Claude, GPT та інших AI-агентів кодування. CLI та веб-сайт використовують ту саму бібліотеку промптів.

Промпти організовані в пакети та робочі процеси. Ви можете переглядати, копіювати до буфера обміну або встановлювати безпосередньо як skills Claude Code.

---

# Перевірка встановлення

Давайте перевіримо, що `jfp` встановлено:

```bash
jfp --help
```

Ви повинні побачити доступні команди та опції.

---

# Перегляд промптів

Перелічіть всі доступні промпти в колекції:

```bash
jfp list
```

Це показує кожний промпт з його ID, заголовком та коротким описом.

---

# Пошук промптів

Потрібно щось конкретне? Шукайте за ключовим словом:

```bash
jfp search "code review"
```

Це фільтрує промпти, що відповідають вашому запиту. Спробуйте шукати теми, релевантні для вашої роботи.

---

# Перегляд деталей промпту

Знайшли щось цікаве? Перегляньте повні деталі:

```bash
jfp show idea-wizard
```

Це відображає повний вміст промпту, метадані та приклади використання.

---

# Копіювання до буфера обміну

Хочете вставити промпт у ваш чат? Скопіюйте його:

```bash
jfp copy idea-wizard
```

Промпт тепер у вашому буфері обміну, готовий для вставки.

---

# Встановлення як skill

Справжня сила: встановлюйте промпти безпосередньо як skills Claude Code:

```bash
jfp install idea-wizard
```

Після встановлення ви можете викликати його в Claude Code:

```bash
/idea-wizard "build a REST API for user management"
```

---

# Веб-альтернатива

Віддаєте перевагу візуальному інтерфейсу? Відвідайте [jeffreysprompts.com](https://jeffreysprompts.com) для красивого UI для перегляду тієї самої колекції.

CLI та веб-сайт мають доступ до тієї самої бібліотеки промптів.

---

# Підсумок

Ви дізналися:
1. **jfp list** — Перегляд всіх доступних промптів
2. **jfp search** — Пошук промптів за ключовим словом
3. **jfp show** — Перегляд повних деталей промпту
4. **jfp copy** — Копіювання до буфера обміну
5. **jfp install** — Встановлення як skill Claude Code

В поєднанні з `ms` з Уроку 11, тепер у вас є повний робочий процес управління skills: знаходьте промпти з `jfp`, керуйте ними локально з `ms`.
