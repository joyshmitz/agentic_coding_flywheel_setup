# Підтримка документації docs/enterprise/

## Про ці документи

Документація `docs/enterprise/` описує систему ACFS з точки зору підприємства:
інструменти, ролі, процеси, інтеграції з ERP.

**Мова:** українська як основна версія. Upstream репозиторій не містить цих файлів.

**Наслідки:**
- НЕ потрібні `.uk.md` дублікати
- Файли вже містять український текст з англійськими технічними термінами
- Завдання — **підтримка актуальності**, а не переклад

### Цільова аудиторія

- Нові розробники (AI-Augmented Developers)
- Agent Orchestrators
- Project Managers
- DevOps / SRE
- HR-спеціалісти
- Operations (облік, витрати)
- Technical leads

### Структура директорії

```

├── 00-system-overview.md            # НАВІЩО: бізнес-цикл, ролі, система

```

## Підтримка актуальності

При змінах в upstream (нові інструменти, оновлені версії, нові можливості):

1. **Перевірити manifest** — `packages/manifest/` є джерелом істини для інструментів
2. **Оновити відповідні файли** — додати/оновити інформацію
3. **Зберегти стиль** — український текст, англійські технічні терміни

```bash
# Перевірити зміни в manifest при upstream sync
git diff upstream/main -- packages/manifest/ --stat

# Перевірити зміни в install скриптах
git diff upstream/main -- scripts/ --stat
```

## Як додати новий інструмент

1. Визначити категорію (AI Agent, Safety, Task Management тощо)
2. Додати в відповідний файл `02a`/`02b`/`02c`
3. Оновити `01-tools-overview.md` (таблиця категорії)
4. Додати інтеграції в `03-tool-integrations.md` (якщо є)
5. Оновити workflows в `04-workflows.md` (якщо потрібно)

## Як додати нову роль

1. Створити файл `NN-role-guide.md` з наступним номером
2. Оновити `00-system-overview.md` (секція Ролі, маршрути)
3. Оновити `README.md` (навігація)
4. Оновити `05-candidate-requirements.md` (вимоги)

### Шаблон ролі

```markdown

## Огляд ролі
## Core інструменти
## Щоденні процеси
## Зв'язок з Odoo
## Метрики ефективності
```

## Правила написання

| Елемент | Мова |
|---------|------|
| Заголовки | Українська |
| Описовий текст | Українська |
| Code blocks | Англійська (без змін) |
| CLI команди | Англійська (без змін) |
| Назви інструментів | Англійська (Claude Code, NTM, UBS) |
| Технічні терміни | Англійська (VPS, SSH, API, CLI, MCP) |
| ASCII-діаграми | Англійська (без змін) |

### Приклад стилю

```markdown
| Інструмент | CLI | Опис |
|------------|-----|------|
| Claude Code | `claude` | AI-асистент для кодингу |
| Aider | `aider` | Парне програмування з AI |
```

## Зв'язок з іншими репо

| Репо | Зв'язок | Що перевіряти |
|------|---------|---------------|
| ACFS (upstream) | Джерело manifest, скриптів | `packages/manifest/`, `scripts/` |
| flywheel_connectors | Реалізація pipes ACFS↔Odoo | Нові connectors, API зміни |
| Odoo (self-hosted / SaaS) | ERP система підприємства | Модулі, що використовуються |
